yt-dlp is a command-line program to download videos from YouTube.com and
other video sites.

It is a fork of [youtube-dl](https://github.com/ytdl-org/youtube-dl).

## Installation

The easiest way to install yt-dlp is to use `pipx`:

```bash
pipx install yt-dlp
```

You can also install yt-dlp manually:

```bash
pip install yt-dlp
```

To upgrade yt-dlp:

```bash
pip install -U yt-dlp
```

## Usage

To download a video:

```bash
yt-dlp <url>
```

To download a playlist:

```bash
yt-dlp --playlist-start 2 --playlist-end 100 <playlist-url>
```

To download a video with a specific format:

```bash
yt-dlp --format 'bestvideo+bestaudio/best' <url>
```

To download subtitles:

```bash
yt-dlp --write-sub <url>
```

To download a video and its subtitles:

```bash
yt-dlp --write-auto-sub <url>
```

To download a video and its subtitles with a specific language:

```bash
yt-dlp --write-auto-sub --sub-langs en,fr <url>
```

To download a video and its subtitles with a specific language, and rename them:

```bash
yt-dlp --write-auto-sub --sub-langs en,fr --sub-lang-en 'English subtitles' --sub-lang-fr 'French subtitles' <url>
```

To download a video and its subtitles with a specific language, and rename them, and download the subtitles in a specific format:

```bash
yt-dlp --write-auto-sub --sub-langs en,fr --sub-lang-en 'English subtitles' --sub-lang-fr 'French subtitles' --sub-format vtt <url>
```
